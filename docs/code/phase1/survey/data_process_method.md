# 文件轉換

- **Docling (由 IBM 開源):** 目前處理 PDF 與 Office 文件的超級新星。速度極快，對表格的辨識能力甚至超越許多付費服務，能將 PDF/DOCX 完美轉為 Markdown。
- **LlamaParse (由 LlamaIndex 推出):** 專為 RAG 打造的雲端文件解析服務。對於複雜排版、內嵌圖表的 PDF 處理能力極強，能自動將圖表轉為文字描述。
- **Unstructured.io:** 多格式處理解析的萬能瑞士刀。支援數十種檔案格式（包含 Word、PDF、Email `.eml`、Markdown、HTML 等），能自動完成分割與元數據提取。

# 網頁爬取

- **Firecrawl**：目前業界極具代表性的工具。開發者只需給定一個網址，它就能自動尋找 Sitemap 並爬取整個網域的所有子頁面，直接輸出結構化的 Markdown 或 JSON。它甚至支援直接與 AI Agent 整合，讓 Agent 在對話中擁有自主爬網頁的工具。
- **Crawl4AI**：這是一個專為建置 RAG 系統設計的開源框架。它的特色是極速且開銷低，不僅能平行處理多個頁面，還能在抓取時直接標註內容的 Metadata，確保 LLM 在後續檢索時不會失去上下文。
- **Scrapfly / Context.dev**：這類 API 服務專注於將網頁內容轉化為「LLM-Ready Data」，讓開發者只需透過單一指令，就能將任何網頁的內文無縫插入到 Agent 的 Prompt 或向量知識庫中。

# 網站資料 RAG

- **混合檢索與重排序（Hybrid Search + Reranking）**：先結合「關鍵字精確比對」與「向量語意搜尋」廣泛撈取不漏接的資料，再透過專屬模型對結果進行二次嚴格計分與重新排序，確保送給大模型閱讀的片段是精準度最高的。
- **GraphRAG（知識圖譜增強檢索）**：將碎裂的文件轉化為由實體與關係交織的網狀知識庫，讓 AI 具備「全局觀」，能夠跨越不同頁面進行複雜的關聯性推理與統整。
- **Agentic RAG（代理式檢索）**：將被動的單次搜尋升級為「具備自主推理能力的工作流」，讓 AI 能主動拆解複雜問題、評估檢索結果，並反覆迭代搜尋直到拼湊出完整答案。

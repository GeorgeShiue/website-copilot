# AI 客服員

目前的 AI 客服已經從傳統的「關鍵字決策樹機器人 (Chatbots)」全面進化為基於大型語言模型 (LLM) 的「自主智能代理 (AI Agents)」。其發展重點不再只是單純的問答，而是強調**人機協同**與**行動導向 (Action-oriented)**。

## 1. 三大核心應用架構

現代 AI 客服系統普遍採用「前台代理、後台輔助、營運洞察」三位一體的架構：

- **自適應 AI 智慧體 (AI Agents - 面向客戶)：**
    - **免程式碼/快速部署：** 放棄繁瑣的樹狀圖設定，改為直接匯入企業現有的知識庫 (Help Center/FAQ) 或網站內容，幾分鐘內即可上線。
    - **自主意圖偵測與多輪推理：** 具備思維鏈 (CoT) 推理能力，能理解複雜語境與模糊提問，不再依賴精確關鍵字。
    - **多步驟行動執行：** 可串接外部 API，直接在對話框內幫客戶完成退款、查物流、修改訂閱等複雜任務。
    - **防幻覺與來源追溯：** 回答時會標註資料來源（Citations），確保答案正確性。
- **真人客服助理 (Agent Copilot - 面向員工)：**
    - **一鍵對話摘要：** 當 AI 無法處理並轉接給真人時，Copilot 會瞬間生成先前的對話摘要，省去人工爬文時間。
    - **語氣調整與擴寫：** 客服只需輸入簡短草稿，AI 即可自動擴寫並調整語氣（如：更專業、更具同理心）。
    - **知識引導：** 在對話過程中，即時向真人客服推薦最適合的內部操作手冊或回覆範本。
- **營運與數據洞察 (CX Intelligence - 面向管理)：**
    - **情緒與意圖分類：** 自動辨識進線問題的緊急程度與客戶情緒，並貼上標籤進行智能分流。
    - **趨勢分析與持續學習：** 主動分析近期熱門客訴話題（Topic Trends），並透過機器學習（如 Resolution Learning Loop）從每次互動中自動優化未來的服務品質。

| **比較維度** | **Zendesk AI** | **Intercom (Fin AI)** |
| --- | --- | --- |

| **主打產品特色** | 強調 **Resolution Learning Loop (持續學習)** 與 **混合式開發模型**（可在固定流程與生成式對話間無縫切換）。 | 強打 **Fin AI Agent** 的高精準度（解決高達 86% 重複問題）以及強大的 **Omnichannel (全通路)** 整合能力。 |

## 3. 傳統機器人 vs. 現代 AI Agent 的差異總結

- **建置時間：** 從「耗時數週拉線設定」轉變為「數分鐘內餵資料生成」。
- **理解能力：** 從「死板比對關鍵字」轉變為「跨語言、具備上下文記憶的語義理解」。
- **解決範疇：** 從「單向提供靜態 FAQ 連結」轉變為「雙向互動並直接執行網站功能」。

# AI 瀏覽器

目前的 AI 瀏覽器發展已正式從「外掛插件時代」邁入「原生整合與代理（Agentic）時代」。瀏覽器不再只是單向呈現網頁的工具，而是轉化為具備**跨分頁上下文理解**、**多模態視覺感知**與**自主行動代理**的智慧個人助理。

## 一、 四大核心技術與功能趨勢

### 1. 跨分頁上下文理解與交叉比對 (Multi-Tab Context)

現代 AI 瀏覽器打破了傳統「單一分頁」的限制，具備同時讀取並理解多個已開啟分頁的能力。

- **應用場景：** 網購比價（同時分析 5 個電商分頁的規格、價格與評價）、旅遊行程規劃（統整多個部落格景點）、學術研究資料交叉驗證。
- **效益：** 消除使用者在不同分頁間反覆切換、複製貼上進行對比的繁瑣痛點。

### 2. 自主行動代理與背景自動化 (Agentic Tasks / Auto Browse)

這是目前 AI 瀏覽器技術競爭的核心天花板。AI 不僅止於「回答問題」，還能「替使用者上網辦事」。

- **運作模式：** 使用者下達高階模糊指令（如：「幫我預約明天的看診」或「買一張最便宜的台北到東京機票」），AI Agent 能在獲得授權後，自主在背景跨網站搜尋、填寫表單、處理多步任務，並在完成後即時回報。

### 3. 視覺語言模型 (VLM) 與網頁圖像操作

AI 開始擁有與使用者同步的「視覺感知能力」，不再單純依賴解析 HTML 原始碼。

- **視覺理解：** 透過螢幕截圖或畫面的視覺識別（如 Copilot Vision），AI 能直接「看懂」網頁上的複雜圖表、資訊圖形或排版。
- **圖像生成與編輯：** 直接在瀏覽器側邊欄透過文字提示詞重塑、擴展或風格化網頁上的圖像，無須跳轉至其他修圖軟體。

### 4. 自訂快捷技能與工作流 (Slash Commands)

為了極大化批次處理效率，各大瀏覽器紛紛導入類似 Slack 或 Notion 的斜線指令（`/`）機制。

- **功能：** 使用者可將高頻使用的提示詞模板（如：事實查核、法條白話文改寫、職缺履歷匹配）儲存為「快捷技能」，造訪任何網頁時只需一鍵即可對當前頁面套用指令。

# AI Web Agent

目前的 AI Web Agent（網頁智慧代理）已正式跨越傳統 RPA 的死板規則與**傳統基於純文本的問答型 RAG**，正在演進為具備**自主規劃、多模態視覺感知、自我糾正與程式碼自主編譯**能力的「大型動作模型 (LAM) 驅動實體」。

---

## 一、 三大指標性開源框架深度解構

### 1. Browser Use：極致輕量與生態系整合的社群寵兒

- **GitHub 狀態：** 突破驚人的 **100k Stars**。
- **核心理念：** 建立一個輕量、自癒（Self-healing）的網頁自動化馬具（Harness），讓任何 LLM 都能像人類一樣擁有瀏覽器的完整操作空間。
- **技術亮點：**
    - **Rust 驅動的核心：** 在 0.13 版本的 Beta Agent 中導入了 Rust 核心，大幅提升底層執行的效能與穩定性。
    - **專屬優化模型：** 推出官方託管的 `ChatBrowserUse()`（如 bu 系列模型），針對瀏覽器任務進行提示詞與推理優化，速度提升 3-5 倍。
    - **真實環境接管：** 原生支援接管本地 Chrome 瀏覽器設定檔（BrowserProfile），完美保留使用者的登入狀態與 Cookie。
    - **技能擴充：** 支援自訂 Tools 工具箱，甚至能與 Anthropic 的 Claude Code 深度整合，讓編碼助理直接開瀏覽器測試。

### 2. Skyvern：視覺語言模型 (VLM) 驅動的企業級自動化

- **GitHub 狀態：** 獲 Y Combinator 支持，達 **22k Stars**，具備 HIPAA 與 SOC2 認證。
- **核心理念：** 徹底放棄脆弱且易因網站改版而失效的 DOM 解析與 XPath 定位，全面改由**電腦視覺 (Computer Vision)** 與 LLM 結合來操作網頁。
- **技術亮點：**
    - **視覺化網頁理解 (Set-of-Marks)：** 透過網頁截圖，利用視覺模型在所有可互動元素上標註數字標籤，讓 AI 透過「看」畫面來下達精確的點擊座標。
    - **強大抗反爬與認證能力：** 原生支援複雜的雙因子驗證 (2FA/TOTP)、整合密碼管理器（如 Bitwarden），並內建 CAPTCHA 驗證碼自主破解與全球 Proxy 網路分流。
    - **低程式碼工作流平台：** 除了提供 Python/TS SDK，還內建了 Docker 部署的視覺化 WebUI，支援 For迴圈、自訂代碼塊與 HTTP 請求等進階編排。
    - **AI 擴充指令：** 在 Playwright 基礎上擴充了 `page.act()` (行動)、`page.extract()` (結構化萃取)、`page.validate()` (狀態驗證) 等高階 API。

### 3. LaVague：Text-to-Action 嚴謹架構的測試與自動化專家

- **GitHub 狀態：** 由 Mithril Security 開發，獲 **6.4k Stars**。
- **核心理念：** 專注於將使用者的自然語言意圖，直接「編譯」轉譯為標準的自動化控制代碼（如 Selenium 或 Playwright 腳本）。
- **技術亮點：**
    - **雙引擎解耦架構：**
        1. **世界模型 (World Model)：** 負責思考與推理，接收目標與當前網頁狀態（HTML/截圖），規劃下一步文字指令。
        2. **動作引擎 (Action Engine)：** 負責編譯與執行，將世界模型的指令編譯成實體程式碼驅動瀏覽器。
    - **RAG 降低 Context 消耗：** 底層深度整合 LlamaIndex。由於現代網頁 DOM 極度龐大，LaVague 利用 RAG 技術僅檢索與當前任務相關的 HTML Chunks（區塊），有效解決脈絡長度爆炸與 Token 成本問題。
    - **LaVague QA 殺手級工具：** 專為測試工程師設計，能將 Gherkin 語法（自然語言測試案例）自動轉為 Pytest 測試程式碼，且能隨網站改版自動修復腳本。

## 三、 2026年 AI Web Agent 的核心技術演進趨勢

1. **從「讀 DOM」走向「看截圖」：** 隨著 GPT-4o、Gemini 1.5/2.0 等多模態視覺模型的普及，視覺驅動（Set-of-Marks）已成為對抗現代單頁應用（SPA，如 Vue 3 / Nuxt 3）動態混淆類名（Class Name）的終極解法。
2. **RAG 技術在網頁操作的必要性：** 如同 Jerry Liu（LlamaIndex CEO）所言，網頁原始碼太大，硬塞會導致模型迷失。透過 RAG 預先過濾、切片 HTML，只餵給 Agent 必要片段，是控制成本與提高準確度的關鍵。
3. **編譯式（Text-to-Action）與解耦架構：** 優秀的框架（如 LaVague）會將「思考（規劃）」與「執行（操作）」分離。這讓 Agent 可以邊跑邊生成/修正腳本，甚至能輸出為確定的自動化代碼，提供極佳的可解釋性（Explainable AI）與除錯錄影。

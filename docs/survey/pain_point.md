# 痛點一：引導流於「口頭指引」，缺乏實質之系統操作與輔助能力

目前多數網站輔助應用（如主流之 AI 客服 Widget）之功能定位仍侷限於對話式的「步驟說明」，將實際執行的認知負荷（Cognitive Load）完全轉嫁予使用者。

- **現況痛點（說明與執行之體驗斷層）：**

    當使用者提出操作流程之詢問時，AI 僅能產出冗長的文本步驟指引。使用者必須一邊閱讀對話框訊息，一邊於複雜的系統介面中搜尋對應之 UI 元件，容易導致操作中斷或錯誤。

- **成因分析：**
    1. **權限與安全壁壘：** 為確保跨網站之通用性並規避資安風險（如 XSS 跨站腳本攻擊），市售 B2B 產品通常採「唯讀（Read-Only）」策略，不介入用戶端之狀態變更。
    2. **前端架構動態性：** 現代單頁應用程式（Single Page Application, SPA）具備高度動態渲染特性，外部通用型 Agent 難以透過單一 CSS 選擇器精準捕捉並觸發事件。
- **技術突破點：**

    由「被動問答角色」轉型為「主動導航與執行體」。提供前端視覺化互動引導（例如動態高亮當前介面之目標元件），並在獲得使用者授權後，透過底層 API 或控制腳本代為完成繁瑣的表單填寫與提交流程。


# 痛點二：過度依賴「即時感知」，缺乏對網站架構之先驗認知

現行的 Web Agent 框架主要依賴「反應式（Reactive）」之即時感知策略，於實際應用中面臨嚴峻的效能與經濟成本瓶頸。

- **現況痛點（缺乏全局地圖之反應式架構）：**

    Agent 增進對網站理解之手段，主要仰賴執行期（Runtime）的 DOM 樹解析或即時網頁截圖。此架構如同缺乏地圖的導航系統，僅能依賴局部視野進行推斷。

- **成因分析：**
    1. **高延遲與 Token 成本爆炸：** 每次互動皆須將龐大的網頁 DOM 結構或高解析度圖片反覆傳輸予多模態模型（VLM）推理，導致回應時間（Latency）過長且運作成本高昂。
    2. **缺乏全域邏輯（Global Context）：** 即時爬蟲無法理解隱含於介面背後的系統架構與業務邏輯。面對結構複雜、歷史悠久或具備舊有 CMS 的網站系統時，Agent 僅具備前端元件感知，無法得知操作對後端資料庫或跨頁面路由產生的連帶影響。
- **技術突破點：**

    將『即時畫面感知』與『預建知識庫』解耦。於 Copilot 導入特定網站前，預先構建完整的網站知識地圖（包含路由架構、業務專有名詞、頁面關聯性）。於執行期間，Copilot 僅需輕量級感知當前之 URL 路由、前端狀態變數（State）或特定 API 回傳值，即可精準調用先驗知識，大幅降低推理延遲並優化操作精準度。

# 痛點三：對話上下文流於「無結構累積」，缺乏長期狀態管理

現行的對話式 Web Agent 多以單一無結構的對話窗口承接使用者所有互動，隨著工作階段拉長，上下文內容日益混雜，導致模型推理品質顯著衰減。

- **現況痛點（上下文污染與注意力稀釋）：**

    使用者在單一工作階段中可能交替提出多個不相關的操作需求，或反覆修改同一設定。由於所有歷史訊息——包含已執行的操作紀錄、已廢棄的指令、以及不同頁面的狀態資訊——皆被壓縮於同一對話窗口，模型難以精準區分「已完成的子任務」、「進行中之目標」與「已失效的參考資訊」，最終產生幻覺（Hallucination）或引用過時的頁面狀態進行推理。

- **成因分析：**
    1. **上下文窗口膨脹（Context Window Bloat）：** 長時間互動累積大量歷史 Token，超出模型有效注意力範圍，導致模型對近期關鍵訊息的擷取能力衰減，發生「遺忘中段」（Lost in the Middle）現象，使回覆偏離當前操作脈絡。
    2. **缺乏結構化狀態追蹤（State Tracking）：** 傳統對話缺乏明確的工作階段區隔與狀態標記機制，無法辨識哪些子任務已經結案、哪些目標仍在進行。模型缺乏狀態感知時，容易將已完成操作的歷史文脈誤認為待執行指令。
    3. **跨輪上下文汙染（Cross-turn Context Pollution）：** 不同網站頁面或不同操作意圖的對話內容在同一個上下文窗口中相互干擾，模型缺乏自動清理已失效參考資訊的能力，導致推理邏輯隨對話輪數增加而逐漸偏移。
- **技術突破點：**

    引入結構化的對話上下文管理機制——將長對話拆分為可獨立管理的「工作階段（Session）」，每個 Session 擁有明確的目標、狀態與生命週期。搭配上下文壓縮（Context Compression）與摘要遞迴（Recursive Summarization）技術，僅保留與當前操作相關的核心資訊，捨棄已失效或不相關的歷史噪聲，從根本上維持長時間互動下的推理品質與回覆準確性。

# 一、 專案技術需求

## 1. 賦予前端視覺引導與後端直接操作能力

- **前端層：** 建立可動態高亮目標 UI 元件、疊加視覺指引的互動引導機制，降低使用者搜尋介面的認知負荷。
- **後端層：** 封裝底層 API 或注入控制腳本，使 Copilot 在獲得授權後能直接代為執行表單填寫、資料提交與跨頁面配置等繁雜操作，而非僅產出文字步驟。

## 2. 以預建知識庫取代即時 DOM 爬取

- **導入前：** 預先建構涵蓋路由架構、API 規格、業務專有名詞與頁面關聯性的「全站知識地圖」。
- **執行期間：** 僅需輕量化擷取當前 URL、前端狀態變數或特定 API 回傳值，即可對應至先驗知識進行低延遲推理，從根本上降低每次互動的計算開銷。

## 3. 導入結構化對話狀態管理機制

- **Session 機制：** 以「工作階段（Session）」為核心劃分對話，每個 Session 具備明確的目標、狀態與生命週期。
- **上下文壓縮（Context Compression）：** 將歷史操作日誌壓縮為結構化意圖狀態，僅保留與當前操作攸關的核心資訊。
- **摘要遞迴（Recursive Summarization）：** 對已完成的 Session 進行摘要遞迴，捨棄已失效或不相關的歷史噪聲，確保多輪互動下的回覆準確性與推理一致性。

# 二、 GitHub Copilot 技術借鏡

## 1. 全站級知識索引與局部檢索機制

- **技術借鏡：** 類比 GitHub 的全域代碼搜尋引擎（Blackbird）與本地向量索引管線。
- **實作策略：** * **靜態預建：** 預先將目標網站的路由架構（Routes）、API 文件、CMS 資料庫結構、操作手冊（FAQ）進行結構化切塊（Chunking）並向量化（Embedding）。
    - **語義檢索：** 當用戶於特定頁面提問時，系統結合關鍵字搜尋與向量語義搜尋，僅擷取最攸關之 HTML 片段與業務邏輯餵給大型語言模型（LLM），大幅降低 Token 消耗與推理延遲。

## 2. 標準化工具調用協定

- **技術借鏡：** 類比 GitHub Copilot Chat 與 Agent Mode 引入之 **MCP 開放標準協定**，實現 AI 跨越編輯器調用終端機、編譯器與外部工具。
- **實作策略：** * **API 封裝：** 將目標網站的後端功能（如 CMS 系統的 Directus API、會員系統、購物車控制等）包裝為標準的 MCP Server 工具箱。
    - **自主決策循環（Reasoning Loop）：** 賦予 Agent 呼叫工具的權限。當用戶下達操作指令時，模型可自主決定調用特定 MCP 工具發送 HTTP 請求，直接完成後端數據變更，而非僅在前端模擬點擊。

## 3. 專項自動化代理與非同步任務

- **技術借鏡：** 類比 GitHub Copilot 的背景智囊模式與 `/research` 自主多檔案重構機制。
- **實作策略：** * **任務拆解：** 面對高度複雜的跨頁面任務（如：「幫我比對本季所有上架文章並修正分類標籤」），Copilot 將啟動非同步之背景 Agent。
    - **自癒執行：** 結合 Playwright 封裝層，Agent 在背景巡覽多個路由、執行批次操作，並內建錯誤反思機制（如遭遇彈出視窗或網路延遲時自動重試），完成後向用戶提交結構化報告。

## 4. 脈絡視窗管理與狀態壓縮

- **技術借鏡：** 類比 GitHub Copilot 針對游標前後文、鄰近開啟檔案（Jaccard 相似度演算法）之動態 Prompt 組裝與記憶壓縮技術。
- **實作策略：** * **狀態監聽：** 輕量化監聽用戶在前端（如以 Vue 3 / Nuxt 3 構建之 SPA 網站）的瀏覽路徑、當前 URL、滑鼠停留區塊及已輸入之表單半成品。
    - **動態壓縮：** 設計狀態編排器（Context Manager），當用戶跨頁面進行連續操作時，定期將歷史操作日誌（Logs）壓縮為結構化的意圖狀態（如：「用戶目前正在進行批次權限變更」），避免長對話導致模型迷失。

# 三、 Website Copilot 技術架構

## 1. 全站知識庫與語義索引管線

- **核心目標：** 突破即時爬蟲的效能與成本瓶頸，完成網站結構的「事前理解」。
- **實作細節：** 開發自動化腳本爬取既有 CMS 內容與網站結構。建立 Vector RAG 知識檢索管線，將網頁路由（Routes）、API 文件與核心文本進行切塊（Chunking）並向量化，完成全站地圖預先索引，供執行期低延遲檢索。

## 2. Agent 推理核心與工具調用機制

- **核心目標：** 賦予大語言模型實體操作與脈絡推理的能力，使其具備安全且可擴充的工具執行環境。
- **實作細節：** 實作基於 ReAct 架構的雙引擎模型（大腦規劃與手腳執行）。將後端 CMS 的核心資料庫操作 API 封裝為標準的 MCP（Model Context Protocol）工具箱，讓 Agent 可安全、自主發送 HTTP 請求進行狀態變更。面對跨頁面批次任務時，啟動背景 Agent 進行非同步執行與錯誤自癒。

## 3. 前端感知層與對話狀態管理

- **核心目標：** 打造輕量化、具備狀態感知能力的對話式操作介面，確保長時間互動下的推理品質。
- **實作細節：** 開發客製化的 Copilot 側邊欄與懸浮 UI 組件。建立全域狀態監聽器，即時同步 Vue Router 的路由變化與前端 DOM 狀態；同時導入 Session 管理機制，將歷史操作日誌壓縮為結構化意圖狀態，僅保留與當前操作相關的核心資訊，捨棄已失效之歷史噪聲。

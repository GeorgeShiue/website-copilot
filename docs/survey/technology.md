# 一、 專案核心願景與技術突破

## **1. 從「純文字被動問答」走向「自動化主動執行」**

突破傳統客服機器人僅能提供靜態文字說明的技術瓶頸，Website Copilot 定位為具備操作能力的**「主動執行代理（Active Agent）」**。在取得使用者授權後，系統可直接連動前端 UI 或調用後端 API，自動化執行如表單填寫、資料檢索與跨頁面配置等繁雜的系統流程。

## **2. 從「局部網頁感知」走向「全域網站知識掌握」**

**捨棄傳統高耗能且高延遲的全頁面 DOM 結構即時爬取**。借鑑 GitHub Copilot 針對代碼庫（Repository）的預先解析機制，本專案於導入目標網站前，將預先建構完整的「全站知識地圖」。在執行期（Runtime）中，系統僅需輕量化擷取使用者的前端局部狀態，即可結合先驗知識，觸發低延遲且高精準度的操作響應。

# 二、 借鏡 GitHub Copilot 之關鍵架構設計

### 1. 全站級知識索引與局部檢索機制

- **技術借鏡：** 類比 GitHub 的全域代碼搜尋引擎（Blackbird）與本地向量索引管線。
- **實作策略：** * **靜態預建：** 預先將目標網站的路由架構（Routes）、API 文件、CMS 資料庫結構、操作手冊（FAQ）進行結構化切塊（Chunking）並向量化（Embedding）。
    - **語義檢索：** 當用戶於特定頁面提問時，系統結合關鍵字搜尋與向量語義搜尋，僅擷取最攸關之 HTML 片段與業務邏輯餵給大型語言模型（LLM），大幅降低 Token 消耗與推理延遲。

### 2. 脈絡視窗管理與狀態壓縮

- **技術借鏡：** 類比 GitHub Copilot 針對游標前後文、鄰近開啟檔案（Jaccard 相似度演算法）之動態 Prompt 組裝與記憶壓縮技術。
- **實作策略：** * **狀態監聽：** 輕量化監聽用戶在前端（如以 Vue 3 / Nuxt 3 構建之 SPA 網站）的瀏覽路徑、當前 URL、滑鼠停留區塊及已輸入之表單半成品。
    - **動態壓縮：** 設計狀態編排器（Context Manager），當用戶跨頁面進行連續操作時，定期將歷史操作日誌（Logs）壓縮為結構化的意圖狀態（如：「用戶目前正在進行批次權限變更」），避免長對話導致模型迷失。

### 3. 標準化工具調用協定

- **技術借鏡：** 類比 GitHub Copilot Chat 與 Agent Mode 引入之 **MCP 開放標準協定**，實現 AI 跨越編輯器直接調用終端機、編譯器與外部工具之能力。
- **實作策略：** * **API 封裝：** 將目標網站的後端功能（如 CMS 系統的 Directus API、會員系統、購物車控制等）包裝為標準的 MCP Server 工具箱。
    - **自主決策循環（Reasoning Loop）：** 賦予 Agent 呼叫工具的權限。當用戶下達操作指令時，模型可自主決定調用特定 MCP 工具發送 HTTP 請求，直接完成後端數據變更，而非僅在前端模擬點擊。

### 4. 專項自動化代理與非同步任務

- **技術借鏡：** 類比 GitHub Copilot 的背景智囊模式與 `/research` 自主多檔案重構機制。
- **實作策略：** * **任務拆解：** 面對高度複雜的跨頁面任務（如：「幫我比對本季所有上架文章並修正分類標籤」），Copilot 將啟動非同步之背景 Agent。
    - **自癒執行：** 結合 Playwright 封裝層，Agent 在背景巡覽多個路由、執行批次操作，並內建錯誤反思機制（如遭遇彈出視窗或網路延遲時自動重試），完成後向用戶提交結構化報告。

### 5. 行內微互動與意圖預測

- **技術借鏡：** 類比 GitHub 編輯器內之 Ghost Text（灰色預測文本）與一鍵 `Tab` 補全體驗。
- **實作策略：** * **主動式引導（Proactive UX）：** 當感知到用戶在某表單欄位停頓、且其歷史軌跡呈現特定意圖時，不等待用戶發問，直接於輸入框旁提供灰色預測內容或快捷填入按鈕，實現無摩擦之微互動。

# 三、 技術面實作里程碑

## **Phase 1：全站知識庫與語義索引管線建置**

- **核心目標：** 突破即時爬蟲的效能與成本瓶頸，完成網站結構的「事前理解」。
- **實作細節：** 開發自動化腳本爬取既有 CMS 內容與網站結構。建立 Vector RAG 知識檢索管線，將網頁路由（Routes）、API 文件與核心文本進行切塊（Chunking）並向量化，完成全站地圖預先索引。

## **Phase 2：Agent 推理核心與 MCP 工具箱開發**

- **核心目標：** 賦予大語言模型實體操作與脈絡推理的能力，使其具備全局視角。
- **實作細節：** 實作基於 ReAct 架構的雙引擎模型（大腦規劃與手腳執行）。將後端 CMS 的核心資料庫操作 API 封裝為標準的 MCP（Model Context Protocol）工具箱，讓 Agent 能安全、自主地發送 HTTP 請求進行狀態變更。

## **Phase 3：前端輕量化感知層與介面整合**

- **核心目標：** 打造無縫嵌入、極致流暢且具備微互動能力的現代化網頁元件。
- **實作細節：** 開發客製化的 Copilot 側邊欄與懸浮 UI 組件。建立全域狀態監聽器，即時同步 Vue Router 的路由變化與前端 DOM 狀態；實作斜線指令（`/`）快捷選單與行內預測文本（Ghost Text）。

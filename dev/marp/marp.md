# 🚀 掌握 Marp 簡報語法
輕鬆將 Markdown 轉換為精美簡報

---

## ⚙️ 基礎設定 (Directives)

Marp 使用最上方的 YAML 區塊來設定簡報的整體外觀。

* **啟用 Marp**：必須在文件最開頭加上 `marp: true`。
* **主題設定**：`theme: default` (內建還有 `uncover` 或 `gaia`)。
* **顯示頁碼**：`paginate: true`。
* **如何換頁**：在空白行使用三個減號 `---` 就能切換到下一頁投影片。

---

## 📝 標題與文字排版

完全相容標準的 Markdown 語法，學習零成本：

# 標題一 (最大的標題)
## 標題二 (次要標題)
### 標題三 (小標題)

* **粗體**：使用 `**粗體文字**`
* *斜體*：使用 `*斜體文字*`
* ~~刪除線~~：使用 `~~刪除線~~`

---

## 📌 列表與引用區塊

### 無序與有序列表
1. 有序列表使用數字加上英文句號（例如 `1.`）
2. 無序列表使用星號（`*`）或減號（`-`）
3. 保持結構清晰，非常適合用來列點說明

### 引用區塊
> 使用大於符號 `>` 可以創建強調的引用區塊。
> 這在展示名言、重要結論或重點提示時非常吸睛！

---

## 🖼️ 圖片與背景處理

Marp 強化了 Markdown 的圖片功能，支援大小與排版調整：

**一般圖片寫法**：
`![圖片描述](圖片連結)`

**控制圖片大小**：
`![width:300px](圖片連結)`

**將圖片設為整頁背景**：
在方括號中加入 `bg` 指令：`![bg](圖片連結)`

## 🧮 數學公式

Marp 可以完美渲染 LaTeX 語法的數學公式。

### 1. 行內公式 (Inline)
使用單個 `$` 符號將公式包起來。
例如：一元二次方程式的標準形式為 $ax^2 + bx + c = 0$。

### 2. 獨立區塊公式 (Block)
使用兩個 `$$` 符號將公式包起來，公式會獨立成行並置中顯示。
例如，一元二次方程式的公式解：

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

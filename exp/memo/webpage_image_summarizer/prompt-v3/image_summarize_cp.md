## 描述品質評估

### 評估維度

基於 RAG 應用場景，使用以下 5 項指標（各 0-10 分）：

1. **事實準確性** - 描述是否避免無根據的推論
2. **資訊完整性** - 關鍵元素是否齊全
3. **檢索可用性** - 頁面關聯與錨點是否有助搜尋
4. **資訊密度** - 單位字數內的有效資訊量
5. **風險控制** - 避免幻覺與過度推斷的能力

## 成本效率分析

### 加權品質評分（按 RAG 用途）

**情景 A：檢索優先**
```
權重：檢索性 50% + 完整性 30% + 準確性 20%

3.1-flash-lite：
  (7.4 × 0.5 + 8.2 × 0.3 + 9.0 × 0.2) = 8.02

3-flash：
  (8.6 × 0.5 + 8.4 × 0.3 + 7.6 × 0.2) = 8.36

差距：3-flash 領先 +0.34 分
```

**情景 B：精確度優先**
```
權重：準確性 50% + 風險控制 30% + 完整性 20%

3.1-flash-lite：
  (9.0 × 0.5 + 9.0 × 0.3 + 8.2 × 0.2) = 8.94

3-flash：
  (7.6 × 0.5 + 7.4 × 0.3 + 8.4 × 0.2) = 7.92

差距：3.1-lite 領先 +1.02 分 ⭐
```

---

### CP 值計算

#### 情景 A：檢索優先（為搜尋效果付費）

```
CP 值 = 加權品質分 / 每圖成本

3.1-flash-lite：8.02 / $0.000811 = 9,891
3-flash：8.36 / $0.001269 = 6,587

CP 值優勢：3.1-lite 高 50%
```

**結論**：即使檢索是優先項，3.1-lite 的 CP 值仍更優。除非檢索性能差 12% 已造成實際損失。

#### 情景 B：精確度優先（為準確性付費）

```
3.1-flash-lite：8.94 / $0.000811 = 11,025 ⭐
3-flash：7.92 / $0.001269 = 6,239

CP 值優勢：3.1-lite 高 77%
```

**結論**：若 RAG 系統容不得幻覺（如法律、醫療應用），3.1-lite 是壓倒性選擇。

## 關鍵發現

### 1. **成本結構顛覆**
- 更便宜的模型（3.1-lite）反而更準確、CP 值更優
- 打破「付費 = 更好」的迷思

### 2. **使用場景分化**
- **精確度導向**（金融、法律）：3.1-lite 勝出 77%
- **檢索導向**（通用搜尋）：3-flash 僅領先 +12%，不足以抵銷成本

### 3. **2 層策略的勝利**
- 用 3.1-lite 初篩 80% 圖片（$0.000649）
- 用 3-flash 複驗 20% 不確定圖片（$0.000254）
- 總成本 $0.000956/圖，保留兩者優勢，CP 值達 8,880（中等偏高）

### 4. **推論風險明顯**
- 3-flash 的推論詞（「服務」「供應商」「用於」）在 RAG 中會造成語義漂移
- 3.1-lite 對推論的抗性強 11 分

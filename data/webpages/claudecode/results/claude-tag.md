[Claude Tag](https://claude.com/product/tag) 是一個 Slack 整合，在您的團隊頻道中以組織的共享身份執行 `@Claude`，具有管理員配置的存取權限。頻道中的任何人都可以在執行緒中標記 `@Claude` 並為其指派任務。請閱讀 claude.com 上的 [Claude Tag 文件](https://claude.com/docs/claude-tag/overview)，以設定並開始使用它。 Claude Tag 適用於 Team 和 Enterprise 方案，與較早的 [Claude Code in Slack](https://code.claude.com/docs/zh-TW/slack) 不同，後者在個別使用者的帳戶下執行每個工作階段。在 Pro 和 Max 方案上，Claude Tag 不可用，Claude Code in Slack 仍然是設定路徑。 是否 助手

Commands 從工作階段內控制 Claude Code。它們提供了一種快速方式來切換模型、管理權限、清除上下文、執行工作流程等。 輸入 `/` 以查看可用的命令，或輸入 `/` 後跟字母以篩選。[命令菜單如何匹配您輸入的內容](https://code.claude.com/docs/zh-TW/commands#how-the-command-menu-matches-what-you-type)涵蓋了突出顯示、拼寫錯誤以及 Claude Code 隱藏的少數命令，直到您輸入其完整名稱。 命令只在您的訊息開始時被識別。命令名稱後面的文字成為其引數。從 v2.1.199 開始，[skills](https://code.claude.com/docs/zh-TW/skills#pass-arguments-to-skills)是例外：一個 skill 調用後跟更多 skills，例如 `/skill-a /skill-b do XYZ`，會載入開始時命名的每個 skill，並將尾部文字作為引數傳遞給每個。最多可以鏈接六個 skills。 如果您在 Claude 回應時發送命令，Claude Code 會將其排隊，並在目前回合完成後執行。Claude Code 會立即執行某些命令而不中斷回應，例如 `/status`、`/tasks` 和 `/usage`。在[全螢幕渲染](https://code.claude.com/docs/zh-TW/fullscreen)中，Claude Code 也會立即開啟對話命令，例如 `/theme` 和 `/help`。在 v2.1.234 之前，Claude Code 會將這些對話排隊直到回合完成。

## 典型工作流程中的指令

大多數指令在工作階段的特定時間點很有用，從設定專案到發佈變更。 **首次在儲存庫中的工作階段。** 執行 `/init` 以產生起始 `CLAUDE.md`，然後執行 `/memory` 以精化它。使用 `/mcp` 設定專案需要的任何伺服器，要求 Claude 建立任何您想要的 [subagents](https://code.claude.com/docs/zh-TW/sub-agents)，並執行 `/permissions` 以設定您的核准規則。 **執行工作期間。** `/plan` 在大型變更前切換到 plan mode。`/model` 和 `/effort` 調整您使用的模型以及它應用多少推理。當對話變得冗長時，`/context` 顯示什麼填滿了視窗，`/compact` 將其摘要以釋放空間。使用 `/btw` 進行不應新增至對話歷史記錄的附帶問題。 **並行執行工作。** Claude 將附帶工作委派給 [subagents](https://code.claude.com/docs/zh-TW/sub-agents)，`/tasks` 列出目前工作階段的背景工作，包括已完成的 subagents。`/background` 分離整個工作階段以繼續作為 [background agent](https://code.claude.com/docs/zh-TW/agent-view) 執行，並釋放您的終端。對於跨越程式碼庫的大型變更，`/batch` 將其分解為獨立單位，並在其自己的 [worktree](https://code.claude.com/docs/zh-TW/worktrees) 中執行每個單位。請參閱 [Run agents in parallel](https://code.claude.com/docs/zh-TW/agents) 以了解這些方法如何相關。 **在您發佈前。** `/diff` 顯示變更的內容。`/code-review` 檢查目前的 diff 是否有正確性錯誤和清理，並可以使用 `--fix` 套用發現；傳遞 PR 編號，例如 `/code-review high 1234`，以改為檢查 pull request。`/review` 是別名。`/code-review ultra` 在雲端執行多代理檢查。`/security-review` 檢查 diff 是否有安全漏洞。 **工作階段之間。** `/clear` 在保持專案記憶的同時開始新工作。`/resume` 返回較早的對話，`/branch` 分支目前的對話以嘗試不同的方向，`/fork` 將其複製到新的 [background session](https://code.claude.com/docs/zh-TW/agent-view)。`/teleport` 將網路工作階段拉入此終端，`/remote-control` 讓您從另一個裝置繼續此本機工作階段。 **當出現問題時。** `/rewind` 將程式碼和對話回復到檢查點，或摘要對話的一部分。`/doctor` 執行設定檢查，診斷安裝和設定問題，並可以修復它們，`/debug` 診斷執行時問題，`/feedback` 報告附加工作階段內容的錯誤。

## 命令選單如何匹配您輸入的內容

Claude Code 會在您輸入時篩選 `/` 選單。下面的每個項目涵蓋您在篩選時可能注意到的一件事：

- **醒目提示** ：Claude Code 只有在 `/` 後面的字母與命令的名稱或別名相符時，才會醒目提示最上面的建議，可以從名稱的開頭或名稱內的某個字開始相符，忽略 `:`、`_` 和 `-` 分隔符。輸入 `/adddir` 會醒目提示 `/add-dir`，輸入 `/new` 會透過其別名醒目提示 `/clear`。按 `Enter` 鍵執行醒目提示的建議。這些醒目提示規則需要 Claude Code v2.1.236 或更新版本。
- **打字錯誤後** ：Claude Code 不會醒目提示任何內容。接近的相符項會保留在列表中，您可以使用 `Tab` 或方向鍵選擇其中一個，但 `Enter` 會按照您輸入的方式提交文字，並報告[未知命令](https://code.claude.com/docs/zh-TW/errors#unknown-command)。
- **您無法使用的命令** ：Claude Code 會將其排除在選單之外。當沒有任何內容相符時，Claude Code 會顯示 `No commands match "/name"`。大多數無法使用的命令在您提交時會傳回[未知命令](https://code.claude.com/docs/zh-TW/errors#unknown-command)；少數幾個，例如[在 Console API 金鑰上的 `/schedule`](https://code.claude.com/docs/zh-TW/routines#schedule-returns-unknown-command)，會改為回答自己的可用性訊息。當您的組織政策停用某些命令時，這些命令也會回答自己的訊息。
- **隱藏命令** ：Claude Code 刻意將一些可用命令（例如 `/heapdump`）保留在選單之外。部分名稱永遠不會將隱藏命令帶入選單：如果部分相符項與任何可見項目都不相符，Claude Code 會顯示相同的不相符訊息。Claude Code 只有在您輸入完整名稱後才會列出該命令，提交完整名稱會執行它。

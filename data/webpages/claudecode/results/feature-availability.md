Claude Code CLI 和所有在本地執行的功能在每個提供者上的運作方式完全相同。如需每個提供者的設定說明，請參閱[企業部署概述](https://code.claude.com/docs/zh-TW/third-party-integrations)。若要直接跳到您的提供者上缺少的功能，請參閱[按提供者摘要](https://code.claude.com/docs/zh-TW/feature-availability#summary-by-provider)標籤。 在下表中，✓ 表示可用，✗ 表示不可用，「請參閱備註」連結到部分支援的註腳。✓ 後面的限定詞會將可用性縮小到該子集，「管理員啟用」表示該功能處於關閉狀態，直到組織管理員將其開啟。

## 按模型提供者的可用性

您的驗證方式決定了 Claude Code 可以存取哪些功能。如需您的提供者上缺少的單一清單，請參閱[按提供者摘要](https://code.claude.com/docs/zh-TW/feature-availability#summary-by-provider)標籤。若要在表格中找到您的欄位：

- **Claude 訂閱** ：您使用 claude.ai 帳戶登入 Pro、Max、Team 或 Enterprise 計畫
- **Anthropic Console** ：您使用 Anthropic API 金鑰進行驗證，或[不使用 API 金鑰登入 Console 帳戶](https://code.claude.com/docs/zh-TW/authentication#sign-in-without-an-api-key)
- **Amazon Bedrock** ：您使用 Amazon Bedrock 模型目錄中的 Claude 模型並設定 `CLAUDE_CODE_USE_BEDROCK`。[Mantle 端點](https://code.claude.com/docs/zh-TW/amazon-bedrock#use-the-mantle-endpoint)（`CLAUDE_CODE_USE_MANTLE`）由此欄涵蓋
- **AWS 上的 Claude Platform** ：您透過 AWS Marketplace 購買了 Claude，但呼叫 Anthropic API，並設定 `CLAUDE_CODE_USE_ANTHROPIC_AWS`
- **Google Cloud’s Agent Platform** ：由 Google 營運；您設定 `CLAUDE_CODE_USE_VERTEX`
- **Microsoft Foundry** ：由 Anthropic 營運；您設定 `CLAUDE_CODE_USE_FOUNDRY`

  - `/voice` 需要 claude.ai 帳戶
  - `/list-agents` 及其別名 `/peers` 僅在[啟用跨工作階段訊息傳遞](https://code.claude.com/docs/zh-TW/cross-session-messaging#availability)的工作階段中可用

- [Zero Data Retention](https://code.claude.com/docs/zh-TW/zero-data-retention)：受您的 Azure 協議約束

**替代方案：** 對於排程，使用 [`/loop`](https://code.claude.com/docs/zh-TW/scheduled-tasks) 而不是 `/schedule`。對於雲端工作階段，使用 [GitHub Actions](https://code.claude.com/docs/zh-TW/github-actions)。 **不可用：** 所有[需要 Claude 訂閱的功能](https://code.claude.com/docs/zh-TW/feature-availability#features-that-require-a-claude-subscription)。[按提供者變化的 CLI 功能](https://code.claude.com/docs/zh-TW/feature-availability#cli-capabilities-that-vary-by-provider)中的所有功能都可用，除了 [fast mode](https://code.claude.com/docs/zh-TW/fast-mode) 需要[已佈建的存取](https://code.claude.com/docs/zh-TW/fast-mode#enable-fast-mode-for-your-organization)。當您的 API 金鑰屬於 Team 或 Enterprise 組織時，[伺服器管理的設定](https://code.claude.com/docs/zh-TW/server-managed-settings)也可用。

## 模型可用性

如需每個提供者和地區可用的 Claude 模型和內容視窗大小，請參閱[模型配置](https://code.claude.com/docs/zh-TW/model-config)和[模型概述](https://platform.claude.com/docs/en/about-claude/models/overview)。Vision、PDF 輸入和擴展思考是模型功能而非 Claude Code 功能，在提供該模型的每個提供者上都有效。[Prompt caching](https://code.claude.com/docs/zh-TW/prompt-caching) 在大多數提供者上的運作方式相同；在 Amazon Bedrock 上，支援因模型而異。

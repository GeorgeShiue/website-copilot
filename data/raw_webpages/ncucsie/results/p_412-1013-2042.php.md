## 入學管道

| 入學管道           | 說明與簡章                                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 特殊選才（一般組） | 包含書面資料審查以及口試。簡章請參閱[中央大學教務處官網](https://admission.ncu.edu.tw/zh-TW/content/37/12)。                                          |
| 特殊選才（資安組） | 包含書面資料審查、口試。簡章請參閱[中央大學教務處官網](https://admission.ncu.edu.tw/)。                                                               |
| 繁星推薦           | 參採在校成績和學測成績。簡章請參閱[大學甄選入學委員會官網](https://www.cac.edu.tw/cacportal/index.php "大學甄選入學委員會官網")。                     |
| 申請入學（一般組） | 第一階段參採學測成績，第二階段指定項目包含書面資料審查以及口試。簡章請參閱[大學甄選入學委員會官網](https://www.cac.edu.tw/)。                         |
| 申請入學（APCS組） | 同申請入學一般組，第一階段增加參採大學程式設計先修檢測 (APCS) 成績。簡章請參閱[大學甄選入學委員會官網](https://www.cac.edu.tw/)。                     |
| 申請入學（資安組） | 同申請入學一般組，第二階段指定項目包含書面資料審查、口試以及筆試。簡章請參閱[大學甄選入學委員會官網](https://www.cac.edu.tw/)。試題範例請參閱此檔案。 |
| 考試入學           | 參採大學考試入學指定科目考試分數。簡章請參閱[大學考試入學分發委員會官網](https://www.uac.edu.tw/)。                                                   |

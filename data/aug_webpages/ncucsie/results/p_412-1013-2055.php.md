### 關於 EMI (English as a Medium of Instruction)

**EMI (English as a Medium of Instruction)** 指在非英語為母語的教育機構中，專業課程的內容傳遞、師生互動、學習教材及學習評量等皆 **100% 使用英語** 進行。 為提升學生國際競爭力，資訊電機學院積極響應國家「2030雙語國家」願景，成立院級 EMI 教育中心。我們透過開設全英語專業課程、舉辦 English Salon 英語交流活動，並提供完善的教學助理 (TA) 培力制度，致力打造優質的雙語學習環境，培育具備國際移動力的頂尖科技人才。 **多元學習資源與支持**

- **English Salon：** 專屬英文交流空間，透過每週不同主題開心練口說。
- **專業課程拓展：** 逐年增加大學部與研究所之 EMI 必修與選修專業課程。
- **EMI TA 培訓：** 完善的助教制度，作為師生溝通橋樑並協助輔導學習。

### 資電學院大學部學生英語能力獎勵

為鼓勵大學部學生提升英文能力，凡在學期間自行參加校內外英文測驗並達以下標準者，可申請專屬獎勵金。請於**領取成績後四個月內** （畢業生須於畢業前）提出申請。

| 測驗名稱                                   | 成績標準                                                       | 獎勵金額上限 | 申請單位       |
| ------------------------------------------ | -------------------------------------------------------------- | ------------ | -------------- |
| 全民英檢 (GEPT)                            | 中高級複試通過                                                 | NT$ 1,600    | 資訊電機辦公室 |
| 多益 (TOEIC)                               | 聽力 ≥ 400分、閱讀 ≥ 385分、口說 ≥ 160分、寫作 ≥ 150分         | NT$ 4,500    | 資訊電機辦公室 |
| 托福 iBT                                   | 閱讀 ≥ 4.5級分、聽力 ≥ 4.5級分、口說 ≥ 4.5級分、寫作 ≥ 4.5級分 | NT$ 5,000    | 資訊電機辦公室 |
| 托福 ITP                                   | 627分以上                                                      | NT$ 1,200    | 資訊電機辦公室 |
| 雅思 (IELTS)                               | Overall 7分以上，且聽說讀寫單項均至少 7分                      | NT$ 5,000    | 資訊電機辦公室 |
| 培力英檢 (BESTEP)                          | 「說、寫」檢定：口說 ≥ 280分、寫作 ≥ 280分                     | NT$ 1,000    | 資工系辦公室   |
| 「聽、讀」檢定：聽力 ≥ 100分、閱讀 ≥ 100分 | NT$ 1,000                                                      | 資工系辦公室 |                |
| **申請限制與注意事項：**                   |                                                                |              |                |

- 「全民英檢」和「多益」僅能**擇一** 申請，且以 1 次為限。
- 「托福 iBT」、「托福 ITP」和「雅思」僅能**擇一** 申請，且以 1 次為限。
- 培力英檢「說、寫」與「聽、讀」檢定合格，各以申請 1 次為限。

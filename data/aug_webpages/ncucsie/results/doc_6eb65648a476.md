| 1. **以修課成績抵免：**<br>進入本系就讀後，在學五學期內修習資格考試所認定之科目 達全班排名前20%或該科成績 90分(含)以上者，得申請抵免該科資格考試。若該班修課人數少，致使前20%不足一人者，以一人計。 <br>2. **以發表論文或獲得發明專利抵免：** <br>(1)曾修習資格考試所認定之科目修課成績及格，曾以本系全銜發表 SCI/SSCI/EI 期刊論文或經學術委員會議認定之國際會議論文申請抵免該科資格考試，且排除本系指導教授及共同指導教授後，學生須為第一作者 (107 學年度入學適用)。申請科目抵免之論文不得列入博士班畢業之著作審查成果。 <br>(2)曾修習資格考試所認定之科目修課成績及格，曾以本系全銜獲得發明專利申請抵免該科資格考試。 (3)前述論文及發明專利如屬同一性質之研究成果，僅得擇一抵免。 <br>3. **以競賽或展演作品抵免：**曾修習資格考試所認定之科目修課成績及格，得以競賽獎項或展演作品申請抵免該科資格考試，申請者得檢具各項有利審查之資料供學術委員審核。 <br>4.除修課成績抵免方式，其餘最遲在學四年內應達成上述規定，否則應予退學。 |  |  |  |  |  |  |  |  |  |

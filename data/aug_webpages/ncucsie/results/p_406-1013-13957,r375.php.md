## 【書報討論】115年9月30日（三）林杰 Jayce Lin 研究員 (Synology)

-演講時間: 115年9月30日（三） 14:00~16:00 -演講地點: E6-A207教室 -演講者: 林杰 Jayce Lin 研究員 (Synology) -演講主題: 全快閃儲存的檔案系統效能之謎 -演講摘要: 全快閃儲存的檔案系統效能之謎 以真實客戶案例開場：一台儲存設備因定期拍攝快照，寫入延遲暴增數百倍。循線深入，解析 Synology 如何在全快閃環境下優化 Btrfs，化解快照問題、突破並行瓶頸，並因應工作負載從 HDD 轉向 SSD 後浮現的新挑戰。下半場介紹 Storage QoS，結合排隊理論與控制回授，說明如何兼顧效能與穩定服務品質。全程串連資料結構、作業系統與排隊理論，呈現課堂知識在真實產品中的實戰應用。 The Mystery of All-Flash File System Performance A real customer incident sets the stage: a storage appliance where routine snapshots sent write latency through the roof — by orders of magnitude. Tracing that failure back to its roots, we unpack how Synology tackled Btrfs performance in all-flash environments: taming metadata explosion and write amplification from snapshots, rethinking locking to unlock concurrency, and confronting the software overhead that surfaces when you stop designing for spinning disks. We then turn to Storage QoS — drawing on queuing theory and control feedback to deliver both peak throughput and predictable service quality. Along the way, the talk grounds each concept in data structures, OS internals, and queuing theory, showing how the fundamentals you learned in class show up in a shipping product. -簡介： 國立清華大學動力機械工程學士、碩士 畢業後曾於研華科技任職 3 年，2017 加入群暉科技，現職主任開發研究員（Staff Product Developer），隸屬儲存部門，負責儲存效能分析與最佳化、I/O 服務品質控制，以及檔案系統層級的資料縮減技術 [ ![line](https://www.csie.ncu.edu.tw/images/stsns/line.png)

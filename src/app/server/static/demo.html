Website Copilot — 嵌入示範（M4a）

兩種嵌入方式共用同一個後端與 widget：

① iframe 嵌入（自有網頁區塊）

在網頁任意位置加入：

<iframe src="http://localhost:8000/static/chat.html"
        width="360" height="520"></iframe>

適合：嵌入網頁中的固定區塊。

② script widget 嵌入（浮動按鈕）

在 </body> 前加一行（本頁右下角已示範）：

<script src="http://localhost:8000/static/widget.js"
        data-endpoint="http://localhost:8000"></script>

右下角出現 💬 按鈕 → 點開對話框 → 串流問答。

提示：點右下角 💬 即為此嵌入方式。
